# 📊 Sales Performance Analysis Dashboard

## 📌 Overview
This Power BI dashboard provides a comprehensive analysis of sales performance across different regions, product categories, cities, and sales representatives. It enables business stakeholders to monitor revenue, profit, customer trends, and operational costs through interactive visualizations.
